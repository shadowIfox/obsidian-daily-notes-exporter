# История изменений

Версии по схеме «главная.дополнительная.исправление» (0.1.1 — исправление в версии 0.1). Даты — по факту выпуска.

## 0.1.1 — в работе
### Исправлено
- Mac: приложение пропадало из Dock и Launchpad («приложение не найдено»). Файл приложения теперь называется `MyDay.app` (в Dock и Launchpad по-прежнему «Мой день»): русское имя файла записывалось в системе двумя способами, и macOS теряла путь.
- Повторный запуск приложения теперь показывает окно уже запущенного, а не создаёт вторую копию.
- Журнал работы приложения пишется в файл (Mac: `~/Library/Logs/com.shadowifox.myday/myday.log`).

### Добавлено
- Английский язык: переключатель «Язык интерфейса» в Настройках (Русский | English). Переведены интерфейс, аналитика и советы, календари, уведомления (в том числе системные), меню значка, экспорт (Markdown, CSV, PDF). Русский остаётся по умолчанию.
- Подпункты у задачи: в окне задачи можно завести чек-лист из подпунктов, в списке задач они видны с прогрессом («2/5») и отмечаются отдельно. Когда отмечены все подпункты, задача завершается сама. Выполненные подпункты учитываются в статистике (график по дням, стрик, разбивка по категориям) наравне с задачами.
- Раздел «Задачи»: новая вкладка «Не сделаны» — только просроченные невыполненные задачи.
- Категория задачи запоминается как маркер: при вводе предлагаются уже использованные названия, не нужно печатать заново. Список маркеров переживает удаление задач; в Аналитике — раздел «Маркеры» со статистикой по каждому (сколько задач было и сколько выполнено) за всё время.

### Планируется в этой версии
- Кнопка «Поддержка» (сообщить об ошибке, предложить улучшение) и опросник для тестировщиков.
- Раздел «О приложении» с версией.

## 0.1.0 — 2026-09-19
Первая версия приложения для Mac и Windows: задачи, привычки, настроение, аналитика, экспорт и резервная копия, база SQLite, меню-бар (значок в трее), глобальная горячая клавиша (⌥⌘N на Mac, Ctrl+Alt+N на Windows), системные уведомления.
