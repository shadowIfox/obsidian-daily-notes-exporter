# 📝 Мой день — задачи, привычки, настроение

Личное веб-приложение: список задач, трекер привычек, опросник настроения, аналитика с графиками и экспорт данных (Markdown для Obsidian, CSV, PDF).

## 🔧 Возможности

- **Задачи** — дедлайн, время, приоритет, категория и заметка (при создании и правке: кнопка «Изменить»), фильтры, редактирование названия по двойному клику, прогресс
- **Привычки** — отметка за сегодня и за любой прошлый день (точки за 7 дней и календарь отметок по месяцам), график по дням недели (серия не прерывается днями вне графика), переименование, архив с возвратом, серия дней подряд, полосы серий
- **Настроение** — оценка 1–5 с заметкой за любую дату (можно записать и исправить прошлые дни, клик по записи в истории открывает её на правку, удаление записи), история за 7 или 30 дней и столбцы за неделю (цвет по оценке)
- **Аналитика** — одна страница с периодом 7 дней / 30 дней / 3 месяца: итоговые карточки со сравнением с прошлым периодом, столбцы задач по дням и дням недели, категории, тепловая карта привычек, линия и кольцо настроения, наблюдения и советы
- **Главная** — приветствие, карточки с мини-графиками (задачи, настроение, привычки, дедлайны), список задач на сегодня / на текущую неделю (Пн–Вс, вместе с просроченными и выполненными) / просроченных и редактирование выбранной задачи (время, приоритет, заметки); справа календарь месяца (номера недель, точки на днях с задачами) и расписание выбранного дня с линией «сейчас», задачу можно добавить прямо из календаря
- **Поиск** (⌘K / Ctrl+K) по задачам, привычкам и заметкам настроения с выбором области, подсветкой совпадений и переходом к найденному
- **Колокольчик** — просроченные задачи, задачи на сегодня, привычки без отметки, незаписанное настроение (после 16:00)
- **Настройки** — имя, тема (системная / светлая / тёмная), экспорт данных за день / неделю / месяц (Markdown, CSV, PDF: со временем, приоритетом и заметками задач), **резервная копия** всех данных одним JSON-файлом и восстановление из неё («Объединить» или «Заменить всё»)
- Данные хранятся в `localStorage` браузера через отдельный слой хранения (см. «Данные»): позже его можно заменить на SQLite без правок интерфейса

## 📦 Запуск

```bash
cd vite-project
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка
```

## ✅ Проверки

```bash
npm run check         # всё сразу: типы, линтер, формат, тесты
npm run test:unit     # юнит-тесты логики (Vitest), около секунды
npm run test:e2e      # проверка интерфейса в настоящем браузере (Playwright), около 3 минут
npm run lint          # ESLint (lint:fix — исправить автоматически)
npm run format        # Prettier (format:check — только проверить)
```

Перед первым запуском браузерных тестов один раз: `npx playwright install chromium`. Dev-сервер они поднимают сами.

- `tests/unit` — Vitest: даты, статистика, поиск, уведомления, графики, хранилище, миграции, экспорт, резервная копия.
- `tests/e2e/storage.spec.ts` — Playwright: сохранение данных, сбои записи и чтения, миграция старых данных.
- `tests/e2e/ported` — 10 наборов проверок интерфейса, перенесённых из временных скриптов без изменений (общий обвяз — `tests/e2e/harness.ts`). Их нужно постепенно переписывать на нормальные локаторы Playwright; пока они исключены из линтера и Prettier.
- Стили (`src/styles`) Prettier не форматирует — они остаются в авторском компактном виде.

## 🗂 Структура `vite-project/src`

| Файл | Назначение |
|---|---|
| `store.ts` | Единственное место чтения/записи данных: `Task`, `Habit`, `MoodEntry`, настройки. Данные читаются в память при запуске (`initStore`), запись идёт следом по очереди |
| `storage.ts` | Интерфейс хранилища `StorageBackend` (асинхронный) и два бэкенда: `localStorage` и память (для тестов) |

| `dates.ts` | Работа с датами `YYYY-MM-DD` в локальном часовом поясе |
| `stats.ts` | Чистые функции статистики (серии, недельные счётчики, сводки главной) |

| `topbar.ts`, `search.ts`, `notifications.ts` | Верхняя панель: поиск (логика в `search.ts`) и уведомления (логика в `notifications.ts`) |
| `calendar.ts`, `taskModal.ts` | Календарь и расписание дня, окно «Новая задача» |
| `viz.ts` | Все графики (HTML и SVG, без библиотек) и подсказки при наведении |
| `todo.ts`, `habits.ts`, `mood.ts` | Разделы приложения |
| `habitDialogs.ts` | Окна привычки: правка, календарь отметок, выбор дней недели |
| `analytics.ts`, `tips.ts` | Аналитика и советы |
| `exporter.ts` | Экспорт в Markdown / CSV / PDF (печать) |
| `backup.ts` | Резервная копия и восстановление (JSON, без DOM) |

## 🗄 Данные

- Всё, что пользователь создал (задачи, привычки, настроение, настройки), читает и пишет только `store.ts`. Другие модули `localStorage` не трогают.
- Физическое хранилище — за интерфейсом `StorageBackend` (`storage.ts`). Чтобы перейти на SQLite, достаточно написать новый бэкенд с методами `read` и `write` и передать его в `initStore(...)`.
- `load*()` отдают копии данных, менять их можно только через `save*()`. Изменение сразу видно в интерфейсе (событие `datachange`), а в хранилище уходит следом; если запись не удалась, приложение говорит об этом (событие `storeerror`).
- **Версия схемы.** Вместе с данными хранится `schemaVersion`. Когда форма данных меняется: увеличить `SCHEMA_VERSION` и добавить шаг в `MIGRATIONS` (`migrations.ts`) — при запуске старые данные и резервные копии пройдут через него сами. Перед миграцией прежние данные сохраняются в ключе `migrationBackup`. Данные более новой версии приложение не трогает и просит обновиться.

## 🎨 Внешний вид

Всё оформление лежит в `vite-project/src/styles/`:

- `tokens.css` — палитра (светлая и тёмная тема), радиусы, отступы, шрифт. **Начинай отсюда**, если хочешь поменять цвета.
- `layout.css` — рамка приложения, сайдбар, верхняя панель, сетки.
- `components.css` — карточки, кнопки, поля, чипы, переключатели.
- `pages.css` — стили отдельных страниц.
- `charts.css` — графики (столбцы, полосы, тепловая карта, кольцо, подсказки).

Графики рисуются своим кодом и берут цвета из тех же CSS-переменных, поэтому сами меняют цвет вместе с темой.

Шрифт — Manrope (пакет `@fontsource-variable/manrope`, работает офлайн).
