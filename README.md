# 📝 Мой день — задачи, привычки, настроение

Личное веб-приложение: список задач, трекер привычек, опросник настроения, аналитика с графиками и экспорт данных (Markdown для Obsidian, CSV, PDF).

## 🔧 Возможности

- **Задачи** — дедлайн, время, приоритет, категория и заметка (при создании и правке: кнопка «Изменить»), фильтры, редактирование названия по двойному клику, прогресс
- **Привычки** — отметка за сегодня и за любой прошлый день (точки за 7 дней и календарь отметок по месяцам), график по дням недели (серия не прерывается днями вне графика), переименование, архив с возвратом, серия дней подряд, полосы серий
- **Настроение** — оценка 1–5 с заметкой за любую дату (можно записать и исправить прошлые дни, клик по записи в истории открывает её на правку, удаление записи), история за 7 или 30 дней и столбцы за неделю (цвет по оценке)
- **Аналитика** — одна страница с периодом 7 дней / 30 дней / 3 месяца: итоговые карточки со сравнением с прошлым периодом, столбцы задач по дням и дням недели, категории, тепловая карта привычек, линия и кольцо настроения, наблюдения и советы
- **Главная** — приветствие, карточки с мини-графиками (задачи, настроение, привычки, дедлайны), список задач на сегодня / на текущую неделю (Пн–Вс, вместе с просроченными и выполненными) / просроченных и редактирование выбранной задачи (время, приоритет, заметки); справа календарь месяца (номера недель, точки на днях с задачами) и расписание выбранного дня с линией «сейчас», задачу можно добавить прямо из календаря
- **Поиск** (⌘K / Ctrl+K) по задачам, привычкам и заметкам настроения с выбором области, подсветкой совпадений и переходом к найденному
- **Колокольчик** — просроченные задачи, задачи на сегодня, привычки без отметки, незаписанное настроение (после 16:00)
- **Настройки** — имя, тема (системная / светлая / тёмная), экспорт данных за день / неделю / месяц (Markdown, CSV, PDF: со временем, приоритетом и заметками задач), **резервная копия** всех данных одним JSON-файлом и восстановление из неё («Объединить» или «Заменить всё»)
- Данные хранятся через отдельный слой хранения (см. «Данные»): в браузере — `localStorage`, в приложении для Mac — SQLite
- В приложении: сохранение файлов через системный диалог, значок в меню-баре, горячая клавиша (⌥⌘N на Mac, Ctrl+Alt+N на Windows) и системные уведомления (см. «Приложение для Mac»)

## 📦 Запуск

```bash
cd vite-project
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка
```

Приложение для Mac (нужен Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`, и Xcode Command Line Tools):

```bash
cd vite-project
npm run tauri dev                    # окно приложения с живой перезагрузкой
npm run tauri build -- --debug --no-bundle   # быстрая сборка без упаковки в .app/.dmg
npm run tauri build -- --bundles app,dmg     # настоящее приложение и образ: src-tauri/target/release/bundle/{macos,dmg}/
cd src-tauri && cargo test           # тесты Rust-части
```

## ✅ Проверки

```bash
npm run check         # всё сразу: типы, линтер, формат, тесты
npm run test:unit     # юнит-тесты логики (Vitest), около секунды
npm run test:e2e      # проверка интерфейса в настоящем браузере (Playwright), около 3 минут
npm run lint          # ESLint (lint:fix — исправить автоматически)
npm run format        # Prettier (format:check — только проверить)
```

Перед первым запуском браузерных тестов один раз: `npx playwright install chromium`. Dev-сервер они поднимают сами.

- `tests/unit` — Vitest: даты, статистика, поиск, уведомления, графики, хранилище, миграции, экспорт, резервная копия.
- `tests/e2e/storage.spec.ts` — Playwright: сохранение данных, сбои записи и чтения, миграция старых данных.
- `tests/e2e/desktop.spec.ts` — Playwright: путь приложения для Mac в браузере с подменой `window.__TAURI_INTERNALS__` (база в памяти): выбор SQLite, перенос из localStorage, настройки уведомлений.
- `src-tauri`: `cargo test` — база SQLite и расписание уведомлений.
- `tests/e2e/ported` — 10 наборов проверок интерфейса, перенесённых из временных скриптов без изменений (общий обвяз — `tests/e2e/harness.ts`). Их нужно постепенно переписывать на нормальные локаторы Playwright; пока они исключены из линтера и Prettier.
- Стили (`src/styles`) Prettier не форматирует — они остаются в авторском компактном виде.

## 🗄 Данные

- Всё, что пользователь создал (задачи, привычки, настроение, настройки), читает и пишет только `store.ts`. Другие модули `localStorage` не трогают.
- Физическое хранилище — за интерфейсом `StorageBackend` (`storage.ts`). В браузере это `localStorage`, в приложении — SQLite (`main.ts` выбирает бэкенд при запуске и передаёт его в `initStore(...)`).
- `load*()` отдают копии данных, менять их можно только через `save*()`. Изменение сразу видно в интерфейсе (событие `datachange`), а в хранилище уходит следом; если запись не удалась, приложение говорит об этом (событие `storeerror`).
- **Версия схемы.** Вместе с данными хранится `schemaVersion`. Когда форма данных меняется: увеличить `SCHEMA_VERSION` и добавить шаг в `MIGRATIONS` (`migrations.ts`) — при запуске старые данные и резервные копии пройдут через него сами. Перед миграцией прежние данные сохраняются в ключе `migrationBackup`. Данные более новой версии приложение не трогает и просит обновиться.

## 🎨 Внешний вид

Всё оформление лежит в `vite-project/src/styles/`:

- `tokens.css` — палитра (светлая и тёмная тема), радиусы, отступы, шрифт. **Начинай отсюда**, если хочешь поменять цвета.
- `layout.css` — рамка приложения, сайдбар, верхняя панель, сетки.
- `components.css` — карточки, кнопки, поля, чипы, переключатели.
- `pages.css` — стили отдельных страниц.
- `charts.css` — графики (столбцы, полосы, тепловая карта, кольцо, подсказки).

Графики рисуются своим кодом и берут цвета из тех же CSS-переменных, поэтому сами меняют цвет вместе с темой.

## 🖥 Приложение для Mac (Tauri 2)

Фронтенд тот же, оболочка — `vite-project/src-tauri` (Rust).

- **База.** `~/Library/Application Support/com.shadowifox.myday/myday.sqlite`. Одна таблица `kv`: ключ (`tasks`, `habits`, `moodData`, `userSettings`, `schemaVersion`, `migrationBackup`) → JSON-текст. Список ключей в Rust (`db.rs`) должен совпадать со `STORE_KEYS` в `storage.ts`. Версия структуры самой базы — `PRAGMA user_version`.
- **Перенос данных.** Если база ещё пуста, а в `localStorage` окна приложения что-то есть, при первом запуске это копируется в базу. Данные из обычного браузера (Chrome, Safari) сюда сами не попадают: у браузера и приложения разные хранилища. Такие данные переносятся через «Резервная копия → Скачать» в браузере и «Восстановить из копии» в приложении.
- **Тема.** Скрипт в `index.html` читает тему из `localStorage` до отрисовки, а база отвечает не сразу — поэтому настройки дополнительно копируются в `localStorage` как кэш (при запуске он обновляется из базы).
- **Файлы.** Экспорт и резервная копия открывают диалог «Сохранить как…» (`utils/download.ts`); выбранный путь получает право записи автоматически.
- **Меню-бар.** Значок «солнце с галочкой» (`shell.rs`): меню «Открыть / Новая задача / Выйти». Красная кнопка окна не завершает приложение, а прячет окно; клик по значку в Dock возвращает его. Выход — «Выйти» в меню-баре или ⌘Q.
- **Горячая клавиша.** ⌥⌘N (Mac) или Ctrl+Alt+N (Windows) из любого приложения открывает окно с формой «Новая задача». Если сочетание занято другой программой, приложение запускается без него (в логе будет предупреждение).
- **Уведомления.** Настройки → «Уведомления», по умолчанию всё выключено. Расписание считает Rust (`notify.rs`, чистая функция `due_notices` с тестами), а не окно: у спрятанного окна таймеры WebView могут «засыпать». Что приходит: по уведомлению на каждую задачу со временем в начале дня; за 2 часа до срока (не раньше начала дня); повторное напоминание о несделанном в выбранное время; по согласию — утренняя сводка и итоги дня с напоминанием про настроение. Уже отправленное записывается в таблицу `notified` (не повторяется после перезапуска; записи старше 14 дней чистятся). Кнопка «Пробное уведомление» заодно вызывает системный запрос разрешения.
- **Иконки.** Исходники в `src-tauri/icons/source` (SVG); набор для macOS собирается `npx tauri icon src-tauri/icons/source/app-icon.png`. Значок меню-бара `icons/tray.png` — монохромный «шаблон», macOS красит его сам.
- **Windows.** Тот же код собирается и под Windows (`.github/workflows/windows-build.yml`, GitHub Actions на Windows-машине; на Mac Windows-версию собрать нельзя). Установщик NSIS ставится без прав администратора, на русском. Отличия от Mac: цветной значок в трее (левый клик открывает окно, правый — меню), горячая клавиша Ctrl+Alt+N (`shell.rs`, `#[cfg(target_os)]`). Установщик не подписан платным сертификатом, поэтому Windows показывает предупреждение SmartScreen («Подробнее → Выполнить в любом случае»). Как запустить сборку и где взять `.exe` — в комментарии в начале workflow. Для передачи тестировщику — папка `~/Documents/Мой день — для передачи` с инструкцией.
- **Не проверено вручную:** работа на Windows целиком (код собирался только на Mac; Windows-ветку проверяла компиляцией на Mac), вид значка в меню-баре, нажатие ⌥⌘N, реальный показ уведомлений и запрос разрешения macOS, печать в PDF через `window.print()` (в браузере работает).

Шрифт — Manrope (пакет `@fontsource-variable/manrope`, работает офлайн).
