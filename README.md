# 📝 Мой день — задачи, привычки, настроение

Личное веб-приложение: список задач, трекер привычек, опросник настроения, аналитика с графиками и экспорт данных (Markdown для Obsidian, CSV, PDF).

## 🔧 Возможности

- **Задачи** — дедлайн (необязателен), категория, фильтры, редактирование по двойному клику, прогресс
- **Привычки** — отметка за сегодня, серия дней подряд, календарь за 7 дней, график серий
- **Настроение** — оценка 1–5 с заметкой, история и график за последние 7 дней
- **Аналитика** — статистика по трём разделам и советы
- **Главная** — приветствие и сводные карточки по задачам, настроению, привычкам и дедлайнам
- **Настройки** — имя, тема (системная / светлая / тёмная), экспорт данных за день / неделю / месяц
- Данные хранятся в `localStorage` браузера

## 📦 Запуск

```bash
cd vite-project
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка
```

## 🗂 Структура `vite-project/src`

| Файл | Назначение |
|---|---|
| `store.ts` | Единственное место чтения/записи данных: `Task`, `Habit`, `MoodEntry`, настройки |
| `dates.ts` | Работа с датами `YYYY-MM-DD` в локальном часовом поясе |
| `stats.ts` | Чистые функции статистики (серии, недельные счётчики, сводки главной) |
| `router.ts` | Навигация по адресу (`#/tasks`, `#/habits` …) |
| `dashboard.ts` | Главная страница |
| `todo.ts`, `habits.ts`, `mood.ts` | Разделы приложения |
| `analytics.ts`, `tips.ts` | Аналитика и советы |
| `exporter.ts` | Экспорт в Markdown / CSV / PDF (печать) |
| `theme.ts`, `utils/chartTheme.ts` | Тема и цвета графиков |
| `icons.ts` | Иконки Lucide (inline SVG) |

## 🎨 Внешний вид

Всё оформление лежит в `vite-project/src/styles/`:

- `tokens.css` — палитра (светлая и тёмная тема), радиусы, отступы, шрифт. **Начинай отсюда**, если хочешь поменять цвета.
- `layout.css` — рамка приложения, сайдбар, верхняя панель, сетки.
- `components.css` — карточки, кнопки, поля, чипы, переключатели.
- `pages.css` — стили отдельных страниц.

Шрифт — Manrope (пакет `@fontsource-variable/manrope`, работает офлайн).
